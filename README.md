## 核心价值

帮助研究者快速回答：

1. 今天真正发生了什么（事实层）
2. 哪些是正式政策，哪些只是媒体热度
3. 政策如何可能传导至产业链与上市公司
4. 哪些环节是真正的“卡脖子”节点
5. 支持证据、反证与未验证假设分别是什么
6. 哪些方向值得继续研究，哪些暂时只能观察

**差异化**：强制证据可追溯 + 政治经济学传导 + 供应链六步卡脖子分析 + 反证优先，而非新闻搬运或概念炒作。

## 核心方法论（整合版）

### 研究链路
政策与财经信息采集  
→ 原文留存与来源分级  
→ 事实摘要（可追溯）  
→ 政治经济学研判  
→ **供应链卡脖子六步分析**  
→ 产业数据与公司财务/估值验证  
→ 市场反应分析  
→ 反证审查  
→ 研究优先级与观察名单

### 供应链卡脖子六步法（来自 Serenity，已适配 A 股）
1. 定位板块所处周期（需求爆发 / 技术跃迁 / 供给受限）
2. 溯源供应链，定位真正卡脖子节点
3. 找 A 股候选标的 + 四维信号卡
4. 六条排除规则过滤伪概念
5. 多空双向确认
6. 输出结构化报告

### 证据三层结构（强制）
- **事实层**：标题、原文、发布时间、机构、财务数据（必须可追溯）
- **解释层**：可能影响（明确标记为“分析判断”）
- **结论层**：研究优先级、情景、观察名单 + 支持证据、反证、未验证假设

### 来源等级
- **A**：法律法规、中央/部委文件、统计公报、交易所/上市公司公告、审计财报
- **B**：新华社、人民日报、央视网、经济日报等权威媒体
- **C**：行业协会、海关、授权行情、券商研报
- **D**：媒体转载、自媒体、社交热榜（仅作线索）
