A 股政治经济学 + 供应链卡脖子研究 Skill。强制证据分层、反证优先、政策传导分析，并用 Serenity 六步法定位供应链瓶颈。

> 这是投资研究工具和分析框架，不是投资建议、荐股服务或收益承诺。

## 这个仓库解决什么问题

它帮助研究者把一条政策或财经热点整理成可追溯的研究过程：

```text
政策与财经信息
→ 原文、来源等级、去重、事实摘要
→ 政治经济学研判
→ 供应链卡脖子六步分析
→ 产业与公司验证
→ 反证、可信度与研究优先级
```

重点回答：

1. 今天真正发生了什么？
2. 哪些是正式政策，哪些只是媒体热度？
3. 政策如何可能传导至产业链与上市公司？
4. 哪个供应链节点可能形成技术、产能或替代约束？
5. 支持证据、反证和未验证假设分别是什么？
6. 哪些方向值得继续研究，哪些只能暂时观察？

## 核心方法论

### 证据三层

- **事实层**：标题、原文、时间、机构、统计口径、公告和财务数据；
- **解释层**：资源配置、执行主体、政策工具、产业传导和约束条件；
- **结论层**：研究优先级、情景、观察名单、支持证据、反证和失效条件。

### 来源等级

- **A 级**：法律法规、中央和部委文件、统计公报、交易所公告、上市公司公告、审计财报；
- **B 级**：新华社、人民日报、央视网、经济日报等权威媒体；
- **C 级**：行业协会、海关、授权行情、券商研究和产业数据；
- **D 级**：转载、自媒体、社交平台和热榜，仅用于发现线索。

### Serenity 六步法

1. 定位板块周期：需求爆发、技术跃迁或供给受限；
2. 溯源供应链，定位真正瓶颈；
3. 找 A 股候选并建立四维信号卡；
4. 用六条排除规则过滤伪概念；
5. 做多空双向确认；
6. 输出结构化报告、反证和跟踪指标。

## 数据与安全边界

公开仓库不包含：

- `.env.local`、API Key、AppSecret、Token、Cookie 和私钥；
- 真实用户、微信身份、会话和审计数据；
- 完整付费观察名单；
- 需要服务端鉴权的行情、财务和付费接口；
- 绕过第三方网站登录或付费墙的代码。

公开案例必须标明数据日期、来源等级和核验状态。没有可靠来源时写“待核验”，不填充猜测。
