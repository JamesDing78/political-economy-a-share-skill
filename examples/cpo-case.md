# CPO 与光互连供应链研究案例

> 类型：公开方法演示，不是当前行情报告。不要把产业叙事直接转换为股票结论。

## 1. 板块周期

需要在每次使用时判断属于需求爆发、技术跃迁还是供给受限，并用订单、价格、产能和客户验证。

## 2. 供应链地图

```text
数据中心 → 交换芯片与光引擎 → 光模块 → 光芯片与激光器 → 衬底、封装和连接器
```

## 3. 卡脖子节点问题

- 是否存在单一或少数供应商？
- 扩产周期是否足够长？
- 国内替代是否有客户验证？
- 公司披露的是主营能力还是概念延伸？

## 4. 四维信号卡

- 卡脖子定位：需要客户、份额、专利或产品认证证据。
- 估值水平：需要最新价格、利润和历史分位。
- 资金与机构：需要授权数据，缺失时标记未知。
- 主营匹配度：以收入、订单和公告为准。

## 5. 反证

1. 终端资本开支可能放缓。
2. 技术路线可能变化，现有设备或材料被替代。
3. 产业链扩产后可能出现价格下行和估值压缩。

## 6. 结论边界

在没有独立政策、产业和公司证据前，状态只能是“仅观察”。
