# 半导体设备供应链研究案例

> 类型：公开方法演示，不代表当前设备采购或公司业绩判断。

## 研究问题

政策支持、国产替代和设备采购之间是否已经形成可观察的订单与现金流传导？

## 供应链地图

```text
晶圆厂资本开支 → 设备整机 → 核心零部件 → 材料与软件 → 维护服务
```

## 六步检查

1. 判断晶圆厂资本开支处于扩张、调整还是结构性替换。
2. 找出制程、良率或交付中最难替代的环节。
3. 检查候选公司的主营收入、客户认证和交付能力。
4. 执行六条排除规则，识别概念业务和高估值风险。
5. 同时列出政策支持、订单和利润证据，以及资本开支下降、客户集中和估值压力。
6. 输出可追溯报告，不输出确定性买卖指令。

## 待核验数据

- 设备采购和招投标；
- 关键零部件国产化率；
- 公司订单、存货、合同负债和经营现金流；
- 毛利率、研发投入、客户集中度和估值历史分位。
