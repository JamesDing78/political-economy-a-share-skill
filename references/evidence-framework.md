# 证据与可信度框架

## 三层结构

| 层级 | 记录内容 | 约束 |
|---|---|---|
| 事实层 | 标题、机构、时间、原文、统计口径、公告和财报 | 不混入推测 |
| 解释层 | 资源配置、执行主体、政策工具、产业传导和约束 | 标记为分析判断 |
| 结论层 | 研究优先级、观察状态、反证和失效条件 | 不输出确定性买卖建议 |

## 来源等级

- A：正式文件、统计公报、交易所公告、上市公司公告、审计财报。
- B：新华社、人民日报、央视网等权威媒体。
- C：行业协会、海关、授权行情、券商和研究机构。
- D：转载、自媒体、社交平台和热榜，仅作线索。

## 三角验证

核心结论至少需要两类独立证据，例如：

```text
政策文件 + 产业数据
官媒表述 + 公司公告
统计数据 + 财报现金流
```

同一篇原文的不同转载不构成独立验证。

## 结论状态

- 已核验：原始来源和独立数据均已确认。
- 部分核验：事实明确，但产业或公司传导仍不完整。
- 仅观察：主要来自热度线索或证据不足。
- 反证较强：存在明显需求、价格、库存、利润或估值压力。
- 已失效：新信息已推翻原判断。
