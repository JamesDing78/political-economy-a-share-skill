政策研究先分层证据，再讨论产业机会。

本方法不把官媒热度、政策口号、概念标签或股价变化直接等同于政策力度、公司订单或基本面改善。

来源如何分级？

A级
法律法规、中央和部委文件、统计公报、交易所及上市公司公告、审计财报。
B级
新华社、人民日报、央视网等权威媒体，主要用于发现与解释线索。
C级
行业协会、海关、交易所数据及研究报告，需确认口径和授权。
D级
转载、社交平台和传闻，仅用于发现线索，不能支撑核心结论。

政治经济学判断要核对什么？

依次核对政策在解决的经济约束、使用的财政或监管工具、执行主体、地方试点、产业链瓶颈和需求传导。资金下达、项目采购和回款节奏必须分别验证。

供应链六步法怎样排除伪概念？

  1. 定位需求爆发、技术跃迁或供给受限；
  2. 溯源供应链并定位真正受限节点；
  3. 建立技术壁垒、产能、客户认证和财务信号卡；
  4. 排除主营不匹配、订单缺失和估值失真的对象；
  5. 进行多空双向确认；
  6. 输出反证、未知假设和失效条件。
